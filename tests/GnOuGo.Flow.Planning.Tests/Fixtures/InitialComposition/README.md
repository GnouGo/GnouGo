# Retained initial-composition corpus

These are sanitized **issued request / committed response** pairs, not responses generated for this correction. They were read through the public encrypted KeyVault record APIs without advancing any session. The catalog contains the twelve original resolved discovery contracts, not the smaller final accepted catalog. Each fixture records the original request and receipt hashes before sanitization.

Sanitization consistently replaces the site/brand with `catalogue.example`/Catalogue, the unrequested interaction category with `preferences`, the workbook location with `workflows/catalogue/records.xlsx`, and local user directories with `/workspace`. IDs, bindings, types, constraints and request/schema structure are preserved except those consistent identifier substitutions. No Browser observations or credentials are included. The source run and original hashes are provenance metadata; sanitized file hashes will naturally differ.

The paired generic corrected composition is executable in `InitialCompositionTests`: it consumes the **actual emitted** `each` declaration and implements the entire worked sequence, reaches review in one deterministic proposal with zero repairs, processes twenty complete pages, selects repeated IDs including the last page, reconnects exact original action arguments, and assembles the header and rows without inference. Incomplete observations and unknown IDs stop before affected actions. `AuthoredCompositionCompatibilityTests` pairs the contradictory assertion failure with separate conditional paths and preserves legitimate explicit inference in handwritten YAML.

The real Browser/Document v15 fixture independently checks visits, exact text, workbook headers/cells/blank positions, paths, closure and committed recovery. These tests prove expressibility, contracts and execution; they do **not** prove a future model will follow the presentation or that a fresh live business outcome will pass.
