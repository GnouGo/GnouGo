Source coordinates established where evidence appeared, but were being used as independent invocation authority. Iteration/workflow enumeration multiplied those coordinates into possible occurrences. Descriptions and detailed rules could therefore compete with the actual result realization.

Interpretation also selected execution kinds and requiredness in semantic obligations while the runtime facet selected those execution facts again. Host source authority only established that its text was policy; it did not establish the nine policy meanings. Those meanings are now declared by their producer, rather than inferred from host names or planner keywords.
