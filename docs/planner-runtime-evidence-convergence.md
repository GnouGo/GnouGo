ConstraintsOnly sources no longer answer a runtime facet. The engine records policy scope and engine-source-authority origin for each issued source scope; semantic policy classification remains model-owned. Old unresolved or model-origin host scopes cannot grant current proof.

Canonical operation admission checks current declaration assignments before creating or reusing local occurrences. It uses the exact owned root/alias/modifier/default evidence, never an expanded context clause. Full coverage excludes a preliminary local occurrence while preserving the governing contract evidence. Separate action spans remain executable. Partial overlap without an independent action span stops with a located diagnostic; no text is cropped or inferred.

The internal local-processing representation, native skeleton, declaration root/attachment semantics, confirmation enforcement and external capability boundaries remain unchanged. Runtime evidence proof is version 2; operation admission proof is version 3. Source proof 4, declaration proof 5 and Schema-5 encrypted storage are unchanged. Current declarations are revalidated at the admission boundary; operation identity remains anchored to the same owned action. Restart recomputes coverage and reuses receipts without duplicating accounting.
