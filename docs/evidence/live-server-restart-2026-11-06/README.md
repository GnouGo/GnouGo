  diagnostic authority through adapters. Recognize a legacy redundant token flag

  existing target. Browser (9 tools), Document (4), Git (22), Cmd (3) and
  GithubCopilot (46) subsequently passed metadata readiness with zero inference.
- Aggregate monetary values with exact scaled integers; conservatively round only
  where decimal capacity requires it. Reject exact overages. Two regressions fail
  before this fix and pass afterward; old charges/snapshots are not repaired.
- Offer implementation-selection evidence only when the existing reader accepts
  its producer/scope/version preconditions. Selected discovery remains available.
  Paired Strict/Diagnostic regressions fail before and pass after. Shorten guidance
  to preserve strict input targets instead of raising them.
- Extend the existing evidence-bound retention variants for explicit cancellation
  and received transient errors with an unfunded retry. Preserve original records,
  complete reservations and old replay/continuation prohibitions.
- Retain structured future financial refusal details through the existing journal
  and budget DTO: scope, origin, allowance, required exposure and prior logical
  dispatch versus unsent next attempt. The old exception detail remains unavailable;
  it is not retrospectively manufactured.
- Resolve test Playwright from staged Release tools instead of a hardcoded Debug
  directory. Keep Kestrel-owned loopback port-zero listeners, timeout/cancellation
  assertions and visible missing-dependency failures.
