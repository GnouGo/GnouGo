# Bounded planning discovery

Format-11 construction selects immediate business work from original requirements and accepted state. Supported local computations and exact inspected operations use their direct paths. Unknown capabilities use the existing scoped discovery phase; there is no global-intent shortlist or second executable plan.

The model chooses capabilities semantically. The host performs exact pagination, caching, contract resolution and eligible description continuations. Reads retain identity, version and provenance. Cycles, inconsistent continuations, stale contracts and repeated evidence without relevant knowledge growth stop rather than invent progress.

Keep full original MCP contracts intact. Compact descriptors help selection but grant no executable authority. Exact schema views preserve mandatory siblings, coupled constraints, alternatives, referenced definitions and normative meaning. Consumed bindings include original producer arguments, nullable interfaces and mode-dependent descriptions. Optional navigation has exact retrieval links; it cannot silently replace mandatory evidence.

Evidence actions request at most eight exact addresses, including automatically followed pages. Selected-provider navigation retains its bounded four-read batch. Resolve and admit a prospective follow-up on a clone before committing evidence, cursor or accounting state. Measure the complete serialized request, including schema and envelope. An indivisible mandatory closure exceeding the captured ceiling stops explicitly without truncation or mid-session escalation.

Current requests and receipts recover byte-exactly. Retired sessions are rejected unchanged; historical financial inspection does not retain old planning readers. Discovery never widens execution permissions.
