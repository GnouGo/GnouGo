# Bounded semantic repairs

The active planner uses internal format 11. It builds one semantic TaskPlan, validates changes on clones and retains exact issued requests and receipts. Retired planning formats cannot be continued or upgraded by a repair. Historical encrypted and financial records remain unchanged.

## Authority

Deterministic compiler findings establish technical defects. Business Judges establish grounded business findings against original obligations and concrete behavior. Missing evidence establishes neither a defect nor editing authority. Runtime execution has separate approval and invocation permissions.

Ordinary construction may replace only its unaccepted fragment. An accepted defect requires an explicit `revise` command bound to the current revision and artifact identity, with `preserveRequirements: true` and exact editable paths. Dependency invalidation preserves unrelated checkpoints and retains invalidated originals as evidence. Scope changes cannot expand effects, permissions or accepted literals.

The existing typed patch schema exposes only authorized slots and compatible values. Removing an optional argument differs from assigning null. Contracts, required values, group isolation, captures, guards, cleanup ownership and provenance remain compiler-enforced. A request retains its captured authority through exact recovery; it cannot be rebased onto newer state.

## Resolution and accounting

Corrections retain the original obligation, affected values, before/after evidence and permitted edits. A new hash establishes a different candidate, not a resolved defect. Cosmetic changes cannot resolve an unchanged required binding; executable transform instructions remain part of behavior.

Revalidate a changed candidate before business review. Explicit host-issued repair intent survives unchanged technical revalidation. Successful scoped repair requires renewed business review and invalidates prior artifact approval.

Use the existing evidence action when a finding needs original context. Context retrieval does not consume the separate single opportunity for supported reinterpretation of the unchanged plan using those proofs. Preserve the report and every request. Evidence and reinterpretation charge calls, tokens and money; actual repairs charge corrections. Repetition without relevant progress stops.
